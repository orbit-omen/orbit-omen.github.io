# OrbitOmen shared media library

This branch is the shared asset source for OrbitOmen websites. Place public images and media under `assets/media/`, organized into folders such as `images/`, `backgrounds/`, `projects/` and `social/`.

The Pages deployment workflow copies `assets/media/` from this branch into the deployed site's `/media/` directory. Do not store secrets, private client files or credentials here; this is a public website asset library.
